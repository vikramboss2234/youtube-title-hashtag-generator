# YouTube Title & Hashtag Generator

A small Python CLI that suggests a clean YouTube title and a starter set of hashtags for a music video.

## Run
```bash
python3 main.py "My Song" "Artist Name"
```

## Why it exists
Music creators in Jaipur and across India often spend more time on packaging than on music. This tool gives a simple, repeatable starting point for titles and hashtags, which creators can then edit in their own voice.

Demo project prepared for the Codex Ambassador application.
